Face Recognition Management
Regenerate Face Embeddings

Regenerate face embeddings for existing face tags using ImageBind model. This is useful after:

  • Switching embedding models (e.g., TwelveLabs → ImageBind)
  • Adding new face tags manually
  • Fixing corrupted embeddings
ImageBind will load once (30-60s), then process each face
Important Notes
  • ImageBind model takes 30-60 seconds to load initially
  • Processing continues in background
  • Safe to run multiple times
  • Only processes faces without embeddings or all faces based on settings
Re-detect Faces in Photos
Bulk Face Detection

Re-run face detection on photos that have no face tags or to find new faces. Useful for:

  • Photos uploaded without "Detect Faces" enabled
  • Fixing photos with missing face tags
  • Re-detecting after threshold adjustments
Detection Notes
  • Uses current threshold (0.95)
  • Saves all detected faces as "Unknown" if no match
  • You can manually tag faces later in Face Manager
  • Safe to run multiple times
